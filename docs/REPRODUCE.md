# Відтворення результатів магістерської роботи

Цей опис дає змогу повторити числа розділу 3 магістерської роботи, зокрема таблиці 3.8 і 3.9, на будь-якій машині без доступу до AWS.

## Версія коду

Результати роботи відповідають незмінному тегу `thesis-v1.0`. Код моделі в `backend/app/engine` і генератор `backend/app/devdata.py` не змінювалися з коміту `2c131ff`, на якому отримано результати. Тег лише додає скрипти `scripts/thesis/`, цей опис і збережені результати в `reports/thesis/`.

```sh
git clone https://github.com/Dem0n4ik/IdentityGuard.git
cd IdentityGuard
git checkout thesis-v1.0
```

## Залежності

- Python 3.12-3.14 (перевірено на 3.13).
- [uv](https://docs.astral.sh/uv/) для встановлення залежностей точно за `uv.lock`.
- GNU Make (необов'язково, команди нижче можна запускати напряму).
- Node.js 22 потрібен лише для збирання вебконсолі, для відтворення таблиць він не потрібен.

```sh
python -m pip install --user uv
uv sync --locked
```

Основні бібліотеки, що впливають на результати: `numpy` (генератор випадкових чисел PCG64), `polars` (побудова профілів і вікон), `pyyaml` (правила виявлення). Точні версії зафіксовано в `uv.lock`.

## Тести

```sh
make test
```

Команда запускає перевірку стилю (`ruff`), перевірку типів (`mypy`) і автоматизовані тести (`pytest`). Без Make: `uv run --locked pytest -q`.

## Відтворення таблиць

```sh
make fetch-stratus        # завантажує журнали Stratus і перевіряє SHA-256
make thesis               # таблиці 3.8, 3.9 та аналіз чутливості
make evaluate-independent # незалежна перевірка на наборі Д4 (підрозділ 3.5.4)
```

Без Make (PowerShell):

```powershell
$env:PYTHONPATH = 'backend'
python -m uv run --locked python -m app.stratus fetch
python -m uv run --locked python scripts/thesis/table_3_8.py
python -m uv run --locked python scripts/thesis/table_3_9.py
python -m uv run --locked python scripts/thesis/sensitivity.py
python -m uv run --locked python -m app.independent_evaluation
```

Результати записуються в `reports/thesis/` (`table_3_8.json`, `table_3_9.json`, `sensitivity.json`), а таблиці виводяться в консоль. Збережені результати еталонного прогону вже лежать у цьому каталозі для порівняння.

| Скрипт | Що відтворює | Очікуваний результат |
| --- | --- | --- |
| `table_3_8.py` | Таблиця 3.8, довірчі інтервали | 857 вікон, 11 з атаками; розширений профіль: TP 11, FP 0, F1 1,000, F1 для R ≥ 50 0,625, F1 для високого рівня 0,706; статичні правила: FP 245 |
| `table_3_9.py` | Таблиця 3.9 | модель 29/36, з правилом 36/36, легітимні регіон і мережа 16/36 (з правилом 20/36), хибних спрацювань 0 з 817 |
| `sensitivity.py` | Підрозділи 3.1, 3.2, 3.5.4 | вікно 15/30/60 хв, параметри профілю s, тривалість бази, поріг недостатньої бази, ваги фактів стану |
| `app.independent_evaluation` | Підрозділ 3.5.4 | 25 вікон, виявлено 1 з 3 вікон атак, 0 хибних спрацювань |

## Дані та безпека

Репозиторій містить лише синтетичні дані. Адреси взято з діапазонів для документації (RFC 5737, RFC 2544), номери облікових записів AWS умовні (`111122223333`, `222233334444`), а облікові записи користувачів мають домен `example.test`. Облікових даних, ключів доступу, токенів і персональних даних у репозиторії немає: секрети задаються лише через змінні середовища, `.env.example` містить порожні значення, а `.env`, бази SQLite і каталог `data/` виключено через `.gitignore`. Перед публікацією репозиторій перевірено пошуком шаблонів ключів AWS, приватних ключів, токенів GitHub і Slack, адрес електронної пошти та реальних IP-адрес.

Журнали Stratus Red Team і набір Ariel Cyber не зберігаються в репозиторії: вони завантажуються з першоджерел за зафіксованими комітами й перевіряються хеш-сумою.
